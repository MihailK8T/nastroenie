# Настроение — демо-сайт Minecraft-сервера

Статический сайт на пять страниц: главная, сервер, тарифы, монеты и аккаунт. Оформление — тёмная «пиксельная» тема с зелёным акцентом.

## Страницы

- `docs/index.html` — главная
- `docs/server.html` — режимы и координаты
- `docs/plans.html` — 10 тарифов от 5 до 200 ₽
- `docs/coins.html` — паки монет
- `docs/account.html` — вход, регистрация, профиль

## Важно

- Аккаунты, тарифы и монеты пока хранятся в `localStorage` браузера. Это демонстрация, а не продакшен.
- Платежи не проводятся.
- Supabase пока не подключён: предоставленный ключ отклоняется как `UNAUTHORIZED_INVALID_API_KEY_TYPE`. Нужен publishable key из Project Settings → API.
