Как подключиться

Версия 1.21.11. Java и Bedrock играют на одном сервере, моды и сборки не нужны.

Java Edition (ПК)

Адрес
kot-mc.myserver.best
Порт
34044 (обычно подставляется сам)
Версия
1.21.11
  1. Установите клиент Java Edition (как скачать — ниже).
  2. Запустите игру и выберите версию 1.21.11 в лаунчере.
  3. «Сетевая игра» → «Добавить сервер» → в поле «Адрес сервера» вставьте kot-mc.myserver.best.
  4. Заходите и в чате выполните /register пароль пароль — это первая регистрация. Дальше при каждом входе /login пароль.

Bedrock Edition (телефон, планшет, консоль)

IP
185.9.145.107
Порт
34047
Версия
1.21.x
  1. Установите Minecraft Bedrock (как скачать — ниже).
  2. «Играть» → «Серверы» → «Добавить сервер».
  3. Название — любое, адрес сервера — 185.9.145.107, порт — 34047.
  4. Подключайтесь и зарегистрируйтесь так же: /register пароль пароль, потом /login пароль. Вход с телефона идёт без аккаунта Microsoft.

Как скачать клиент

Java Edition на ПК (Windows, macOS, Linux)

  1. Откройте официальный сайт minecraft.net/download и скачайте лаунчер для своей системы.
  2. Установите лаунчер и войдите в аккаунт Microsoft (тот же, что для Xbox). Купить игру можно там же, на minecraft.net, — это единственный официальный способ.
  3. В лаунчере откройте вкладку «Установки» → «Новая установка» → версия 1.21.11 → «Создать».
  4. Вкладка «Играть» → выберите созданную установку → «Играть».
  5. Дальше «Сетевая игра» → «Добавить сервер» и адрес kot-mc.myserver.best.

Если Minecraft уже куплен, скачивать ничего заново не нужно — достаточно выбрать версию 1.21.11 в лаунчере. Моды, Forge и OptiFine для входа не требуются.

Bedrock Edition на телефоне и планшете

  1. Android: Google Play → «Minecraft» (издатель Mojang) → «Установить». Платная версия, есть пробная.
  2. iOS/iPadOS: App Store → «Minecraft» (разработчик Mojang) → «Загрузить».
  3. Откройте игру, войдите в аккаунт Microsoft (можно создать бесплатно прямо в игре).
  4. «Играть» → «Серверы» → «Добавить сервер»: адрес 185.9.145.107, порт 34047.

Bedrock на консоли и Windows

  1. Windows 10/11: Microsoft Store → «Minecraft for Windows».
  2. Xbox: магазин консоли → «Minecraft». PlayStation и Switch — только официальная версия из магазина консоли.
  3. На консолях сторонние серверы по IP обычно недоступны: подключайтесь с ПК или телефона.

Версия клиента должна совпадать с сервером: Java — 1.21.11, Bedrock — 1.21.x. Если лаунчер пишет «версия не поддерживается», обновите игру до последней.
